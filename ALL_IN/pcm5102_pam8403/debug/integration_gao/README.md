# 当前整合顶层的板上诊断

该工程引用主工程当前启用的子模块和 CST/SDC，保留触摸、压力、手势、S1 吉他和同一组 I2S 引脚。`prepare.ps1`从当前`src/top.v`生成`src/top_probe.v`快照，仅追加保留的观测寄存器，并关闭输出寄存器放入 IOB，便于采集输出节点。观测值全部比原信号晚一个50MHz时钟（20ns），不控制音频逻辑。主工程源码与正式位流不被覆盖。

准备和构建：

```powershell
./prepare.ps1
& 'D:/G/Gowin/Gowin_V1.9.11.03_Education_x64/IDE/bin/gw_sh.exe' ./build.tcl
```

下载本目录 `impl/pnr/ao_0.fs` 到 FPGA SRAM，在 Gowin Analyzer Oscilloscope 中打开 `INTEGRATION_GAO.gao`。不要把旧 `audio_gao` 工程的探针配置用于这个位流。

## 采集方法

1. 上电或下载后等待至少 1 秒，让触摸启动等待完成。
2. **先按住 S1 至少 50ms，再 Start，然后 Force Trigger。** 默认 S1 边沿触发如果在按下瞬间捕获，81.92us 窗口短于 5ms 消抖，无法观察到后续拨弦。
3. 另存一份“不按 S1、按住触摸 OUT1 至少 50ms”的强制触发采集。
4. 导出 CSV，Clock period=20ns，每次使用不同文件名。

按住 S1 时，只在最初按下触发一次拨弦；长时间保持后尾音可能衰减完。采集应在刚按下约 50～100ms 时完成，需要重测时先松开再按。

## 按信号确定问题在哪一级

| 观察信号 | 判读 |
| --- | --- |
| `resetn` | 启动后应为 1；为 0 时所有音频逻辑仍在复位 |
| `key_s1` | 松开 0、按住 1；不变化时先检查物理 S1、板型和 H11 |
| `touch_out` | 按触摸键时相应输入位应变化；原始输入不变化不能用修改 DDS 解决 |
| `touch_ready` / `touch_keys` | 约600ms启动后 ready=1；输入稳定约2ms后对应触摸键为1 |
| `guitar_scaled_sample` | S1重新按下并完成消抖后应出现变化的非零拨弦样本 |
| `touch_mix0` | 按住音符键时应出现变化的非零样本 |
| `fsr_gain` | 默认压力增益在16384～65535，压力模块异常也不应把它变成零；该增益不作用于S1吉他 |
| `gesture_ready` / `gesture_sample` | 手势初始化状态与手势音频；初始化失败不应阻止S1和触摸发声 |
| `audio_sample` | 最终混音，若源样本变化但最终长期为零或恒定饱和值，重点查混音或其他音源 |
| `i2s_bck` / `i2s_lrck` / `i2s_din` | 正常输出BCK周期320ns、LRCK周期20.48us；非零PCM需要在DIN上有相应串行数据 |

采集总时长为81.92us，只覆盖约4个音频帧。PCM样本可以在帧间保持不变，不能要求每个50MHz采样点都变化。片内I2S捕获不能证明DAC接收引脚电压、DAC模拟输出和功放声音正常。

## 接线核对

| J3物理脚 | 当前用途 |
| --- | --- |
| 1 / K2 | PCM5102 BCK |
| 2 / K1 | PCM5102 LCK/LRCK，不能同时接TTP229 OUT1 |
| 3 / L1 | PCM5102 DIN |
| 5 / K4 | TTP229 OUT1 |
| 23 / H4 | APDS SCL |
| 24 / G4 | APDS SDA |

若同一套DAC/功放/喇叭在旧工程可用，优先保持其已验证的配置，检查整合后新增信号是否接到原音频引脚。PCM5102芯片三线模式要求SCK为低、XSMT为高、FMT为低；模块可能已通过焊盘/电阻设置这些电平，不能凭H1～H4标签猜测功能。依据：[TI PCM510xA数据手册，芯片引脚表与9.3.5.3节](https://www.ti.com/lit/ds/symlink/pcm5102a.pdf)。
