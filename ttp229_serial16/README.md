# TTP229-BSF：固定 16 键最小验证工程

适用当前 Tang Primer 25K / GW5A-LV25MG121NC1/I0，输入时钟 50 MHz。
打开 `TTP229_SERIAL16.gprj`，顶层是 `ttp229_serial16_top`。
此工程上电直接轮询全部 16 键，无需按 S2 选择模式。

你已确认模块是 **TTP229-BSF、VCC/GND/SCL/SDO，并已装 TP1、TP2 黄色跳帽**，
配置与参考文章相同：**16 键、高有效串口**。保持这两个跳帽，不需要另焊电阻。
芯片选项由跳帽经板载高值电阻设置；焊盘未改不代表芯片选项仍是默认值。
程序不能修改芯片的上电选项。

## 保持 TP1、TP2 跳帽，再接四根线

本程序和核心驱动现在都默认 `ACTIVE_LOW=0`，匹配已装 TP1 跳帽的高有效串口。
如果以后拆除 TP1 跳帽、恢复低有效模式，须把顶层 `ACTIVE_LOW` 改为 1 并重编译。

| 芯片选项 | 本次配置 | 用途 |
| --- | --- | --- |
| TP0 / OPDEN | 保持原状 | 不用于本次 16 键串口选择 |
| **TP1 / SAHL** | **保持黄色跳帽，经板载高值电阻下拉** | **高有效，与当前程序匹配** |
| **TP2 / KYSEL** | **保持黄色跳帽，经板载高值电阻下拉** | **启用 16 键** |
| TP3、TP4 | 先保持原状 | 单键模式，先逐个验证 16 个键 |
| TP5～TP7 | 保持原状 | 无需改动 |

你当前已通过跳帽完成 TP1、TP2 配置，以下电阻说明仅供移植到其他模块参考。
官方应用说明推荐 820 kΩ；模块若已装 1 MΩ 配置电阻，可沿用。
这些选项与触摸电极共用引脚，**不要把芯片 TP2 直接用导线短路到地**。
如果模块焊桥已串联高值电阻，闭合正确的焊桥即可；否则加装高值电阻。
不同模块的 P1/P2/焊桥编号不统一，不能仅按焊桥号码猜。
应确认该配置路径连接的是 **芯片 TP2/KYSEL（SSOP-28 第 2 脚）**。
芯片脚号以封装定位点为准；模块面板“按键 2”不等于芯片 TP2。

改好选项后，让模块真正断电再重新上电。只重新下载 FPGA 不会重锁存这些选项。
**上电后前 1 秒不要触摸面板**。先单键测通；若需要同时按多个键，
再将 TP3、TP4 **分别**经上述高值电阻下拉，并给模块重新上电。

依据：[用户指定文章](https://www.cnblogs.com/helesheng/p/16395463.html)、
[通泰 BSF 官方手册第 7～9、12～14 页](https://www.tontek.com.tw/uploads/product/97/TTP229-BSF_V1.1_EN.pdf)。
文章中“15 键”是笔误；TP2 下拉选择的是 16 键。

## 四线接线表

以下编号对应 **Tang Primer 25K Dock 60033 官方原理图** 的连接器物理脚号，
不是 FPGA 球号，也不是示例里的数组下标。按排针 1 脚标记数脚，勿按照片方向猜。

| TTP229 模块 | FPGA 底板接点 | FPGA 球号/方向 |
| --- | --- | --- |
| **VCC** | **J4 第 1 脚的 3.3 V** | 电源；J4 第 2 脚也是 3.3 V |
| **GND** | **J3 第 12 脚 GND** | 公共地；J4 第 3/4 脚也可用 |
| **SCL** | **J3 第 37 脚** | **F6，FPGA 输出 → 模块输入** |
| **SDO** | **J3 第 38 脚** | **F7，模块输出 → FPGA 输入** |

**J3 第 11 脚是 5 V，不能作为本次模块的 3.3 V 电源。**
J3 没有 3.3 V 电源脚；也可从空闲 J5/J6 的第 1/2 脚取 3.3 V。
串口 SDO 是 CMOS 输出，所以本接法让模块与 FPGA 都使用 3.3 V。
F6/F7 必须空闲；如果 J3 插着 SDRAM 扩展板，先拔掉扩展板。

拆掉此前 SCL 接 GND/3.3 V 的固定连线，再连接 FPGA 的 SCL 输出。
本次只接这四根模块线，OUT1～OUT8 全部不接：16 键模式下这些脚复用为触摸电极。
建议先关闭并断开 HUB75E、音频等外设，接线尽量短。

排针/LED 依据：[Sipeed Dock 原理图第 1 页](https://dl.sipeed.com/fileList/TANG/Primer_25K/02_Schematic/Tang_Primer_25K_Dock_60033_Schematic.pdf)。

## 如何判断已工作

烧录本工程后：

1. **LED4 / DONE（D7）持续闪烁**：证明 FPGA 时钟和新工程正在运行。
2. 等 1 秒后，逐个触摸 K1～K16，先每次保持约 0.5 秒。
3. **LED3 / READY（E8）在任意键确认按下时亮，松开后灭**。

两盏灯为高电平点亮。本工程已在构建脚本中开启 READY/DONE 的 GPIO 功能。
看到 LED4 闪烁只证明 FPGA 在运行；必须触摸键时 LED3 有响应，才能确认触摸链路。

串口可进一步确认键编号。参数：**115200，8N1，无流控**。
用当前底板 **J8 USB-C 调试口**连接电脑，打开它对应的虚拟 COM 口，
不需要额外接串口线。FPGA TX=C3 已通过底板接到 BL616 的 UART RX。
若系统未出现 COM 口，先检查数据线与底板调试器驱动；LED 验证不依赖串口。
每 100 ms 输出一行，`R` 是完整原始帧，`K` 是去抖后的 16 位按键位图：

```text
R=0000 K=0000     没有按键
R=0001 K=0001     K1
R=0002 K=0002     K2
R=0080 K=0080     K8
R=0100 K=0100     K9
R=8000 K=8000     K16
R=8001 K=8001     K1+K16（须先配置多键）
```

`K` 是十六进制位图，不是十进制编号。例如 K16 对应 `8000`，不是 `0016`。
bit 0 对应模块 K1，bit 15 对应 K16；若面板从 0 编号，按其实际编号对应。
当前高有效版本的 SDO 输入保留内部上拉。若 SDO 未接，可能持续读到 `FFFF`、LED3 常亮；
这时先检查 SDO 连线及极性。正确连接模块、没有触摸时应读到 `0000`。
驱动不提供模块存在检测，仍需观察真实触摸后的按下/松开变化。

## 代码与时序

- 核心驱动：`src/ttp229_serial16.v`，可单独移植，不依赖显示或音频工程。
- 演示顶层：`src/ttp229_serial16_top.v`，自动上电复位、LED、串口报告。
- 可选串口报告：`src/ttp229_uart_report.v`；使用按键功能不需要串口。
- 默认启动等待 1 秒；每帧完整 16 个时钟，不提前退出。
- SCL 空闲低；上升沿后等待 10 μs，在高电平结束前采样已经两级同步的 SDO，
  随后恢复低。按下为高，高、低各 10 μs，读取频率 50 kHz，一帧 320 μs。
- 帧结束后静置 10 ms，使芯片串口超时机制重新对齐到第一个键。
- 每键独立连续 3 个完整帧确认按下和松开。第一个不同帧到确认约 20.64 ms；
  对芯片已经输出的新状态，另加轮询相位后约 20.64～30.96 ms。
- 芯片本身还有检测/休眠唤醒延迟，所以这里的消抖时间不等于总触摸响应时间。
- 所有 FPGA 逻辑都使用 50 MHz 时钟；SCL 仅为输出，不充当内部时钟。

驱动接口：`raw_keys[15:0]`（完整原始帧）、`keys[15:0]`（稳定状态）、
`key_press[15:0]` / `key_release[15:0]`（确认变化时的单时钟脉冲）、
`frame_valid`（完整帧脉冲）、`ready`（启动等待结束）。
`ready` 不代表检测到模块存在或模块一定校准完成。
应用逻辑应使用 `keys` 或 `key_press`，不要直接拿 `sdo` 当按键输入。

文章示例使用 **TP1 已下拉的高有效模式**，与你已装 TP1、TP2 跳帽的配置相同。
本工程当前默认匹配该高有效模式；若以后拆下 TP1，须把顶层 `ACTIVE_LOW` 改为 1 并重编译。
该参数同时改变 SCL 极性和 SDO 解码，而不是只取反数据。

## 编译与下载

本目录下运行：

```powershell
.\tools\run_sim.ps1
.\tools\build.ps1
```

也可在 Gowin IDE 打开 `TTP229_SERIAL16.gprj` 后编译。
工程保存的配置与 `tools/build.tcl` 包含 READY/DONE GPIO 选项。
如果复制源码另建工程，必须自行开启这两个选项，否则 LED 引脚无法布局。

Gowin Programmer 选择 `GW5A-25A`，使用 **SRAM 下载**先测试，文件指向：

```text
ttp229_serial16/impl/pnr/TTP229_SERIAL16.fs
```

不要选旧音频、HUB75E 或 `ttp229_gpio` 的位流。SRAM 下载断电会丢失；
配置模块后先上电、等 1 秒，再下载并测试也可以。
本轮生成了位流，但没有自动下载到硬件；模块跳线/接线完成后的实测仍需执行。
结果与位流校验值见 `VERIFICATION.md`。

## 先按这条顺序排查

| 现象 | 优先检查 |
| --- | --- |
| LED4 不闪 | 下载文件是否是本工程，50 MHz 时钟/电源是否正常 |
| LED4 闪，所有键无反应 | 共地、SCL/SDO 是否接反，37/38 是否数错，TP1 跳帽是否装好且重新上电 |
| K1～K8 正常，K9～K16 不正常 | TP2 下拉是否通过高值电阻，模块是否真正断电重上电 |
| 单键正常，同时两键不正常 | TP3 与 TP4 是否都经高值电阻下拉并重新上电 |
| 无触摸时却常亮或出现乱键 | SDO 是否断线被上拉或短到 3.3 V、TP1 极性、供电/去耦、触摸电极外接线 |

有示波器/逻辑分析仪时，F6 应是空闲低、16 个高脉冲，每个高脉冲 10 μs，
脉冲串每约 10.32 ms 出现一次。芯片第 13 脚 SCL 应收到相同波形。
逐个触摸时，在芯片第 12 脚 SDO 的相应数据槽应能看到高电平变化。
