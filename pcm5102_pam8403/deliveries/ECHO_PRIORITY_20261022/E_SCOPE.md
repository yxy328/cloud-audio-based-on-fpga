# 阶段 E：100 CLS 预留下的范围复核

2026-10-21。用户已确认将 E 的 CLS 预留由 280 降至 **100**；Logic 仍为 **600**，BSRAM 仍为 **0～2**。该确认不增加命令号、DSP 或其他阶段的预算。

## 预算边界

| 阶段 / 保留项 | Logic | CLS | BSRAM |
| --- | --- | --- | --- |
| C | 400 | 100 | 0 |
| D | 150 | 30 | 0 |
| B2 | 900 | 200 | 0～2 |
| E | 600 | **100** | 0～2 |
| 安全垫 | — | 35 | — |
| 总计 | 2050 | **465** | 0～4 |

相对 0.4 基线余量 2101 Logic / 465 CLS，该表闭合。B1 实测余量为 2073 Logic / 467 CLS，不能用 C 的节省自动扩张 E；B2 和安全垫仍保留。每项以完整工程 PnR 的五项资源差值验收，单模块估算不能代替整机数据。

## 缩减后的功能范围

原方案“三音源 × 七能力族全覆盖”撤为交付承诺；E 成为逐项准入阶段。施工顺序仍为 **E0 → E4 → E2 → E3 → E1**，在边界内做完一项再判断下一项。下表是准入范围，尚未开始 E 的 RTL 或 App 实施。

| 项目 | 100 CLS 内的准入范围 | 本轮不承诺的范围 |
| --- | --- | --- |
| E0 音源区分 | 先核对现有事件生产者标识和声部锁存；只为随后获准的参数增加必要字段 | 预先复制三套整机状态、包络和音色表 |
| E4 音量 / 力度 / 震音 | 优先评估利用已有 GAIN 乘法时隙的分源静态音量；无 DSP 增量才可准入 | 三轨独立 LFO 和逐声部震音、完整力度曲线编辑器 |
| E2 音高 | C7现只保留红外 /手势共享移调与A4；优先评估静态逐弦定弦，触摸调音恢复需另测资源，不自动转入E预算 | 同时承诺定弦、演奏中逐声部弯音、独立律制三项 |
| E3 表情 | 保留 C 的共享颤音与全局起振等待；仅在前项通过后评估分源参数锁存 | 32 套起振计数器、逐声部滑音、手势连弓三项一起上线 |
| E1 音色 | 末项单独测量，只有剩余额度允许才进入 | 新增 DSP 谐波混合器、三套完整自定义音色与谐波权重表 |

红外 / 手势的 HOLD 与复音限制继续显示为未实现，不把它们算入上述七族已覆盖项。C8 的律制原型超出 C 预算而撤回，也不能改记到 E 的预留中。

## 准入和停止条件

1. 启动 E 前，重新读取 D、B2 交付后的完整报告；检查 E 的 600 Logic / 100 CLS 以及安全垫仍然存在。
2. 先列命令号与聚合字段表给用户确认，再做协议修改。四档回声优先版已用59 /60 /62号，只有61 /63号未分配；回复kind30 /31为空。不能据此推断多个命令族都能单独占号；AREC的七条命令及原回复kind继续占用原位。
3. 每个候选项先完成具体实现、相关仿真、完整 PnR 和 App 核心测试；新增成本累计不得超过 E 预留。触及边界时退回该候选项，并报告实测差值。
4. 安全垫、B2 预留及其他尚未开始阶段的预留不参与挪用。E1 首先退出；其他项按实际依赖停止，不用“全覆盖”作为超预算理由。

本页没有将任何 E 项记作已实现，也没有把未测的“低成本”描述换算成可用 CLS。C 的最终实现、拒绝原型和资源数据见 [PERFORMANCE_PARAMS.md](PERFORMANCE_PARAMS.md)。
