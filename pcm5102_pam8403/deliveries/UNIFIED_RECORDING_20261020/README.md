# 单固件统一录制版

烧录 **PCM5102_UNIFIED.fs**，安装 **FPGA-Music-Unified.apk**。同一份 FPGA 固件包含正常演奏、曲谱、LED/遥控、板上事件录制重放、Flash PCM 原音质录音及 HC-05 WAV 回传，无需在普通版和音频版之间换烧。

器件：GW5A-LV25MG121NC1/I0（TP-25K）。HC-05 串口保持 9600 bps。统一版的事件录制通过 APP 按钮操作，16 键模式中的琴键继续用于演奏。

## 使用

1. 按现有接线烧录本包的 `PCM5102_UNIFIED.fs`。
2. 安装本包 APK，选择已配对 HC-05 连接，读取录制状态。
3. 按所需录制方式使用对应区域：

- **手机琴键与我的录音**：开始手机录制 → 弹奏页面琴键 → 停止 → 手机立即回放 → 命名保存。每次保存新增一份，可改名、确认删除、导出 MIDI，重开后恢复；每份最多 10000 个音符，数量由可用空间决定。无需蓝牙。
- **事件录制与板上重放**：开始录制 → 弹奏实体琴键/音源 → 停止 → 板上重放。需要断电保留时再保存到 Flash。与手机本地录制分别保存。
- **HC-05 原音质录音**：准备空闲槽 → 开始录制 → 弹奏 → 停止并校验 → 回传 WAV → 手机播放/导出。记录最终数字混音，48828.125 Hz、16 位单声道，最长 30 秒。

事件录制与 PCM 录制按需切换，共用 Flash 引擎并使用不同分区。准备 PCM 槽会擦除非当前槽，保留上一条有效 PCM 录音。

9600 bps 下，30 秒未压缩音频回传约需 **54 分钟**；原音质 WAV 需要传完才能在手机完整播放。回传期间 APP 的蓝牙控制等待回传结束或取消，实体演奏和 LED 可继续运行。需要停止后手机立即回放时，使用手机本地音符录制。

新 APK 收到完整的 `ERR,STATE`、`ERR,CMD`、`ERR,BUSY` 等设备拒绝时会显示原因并保留蓝牙连接。旧普通固件缺少的录音功能仍需通过烧录本包统一固件获得。

## 验证结果

成功构建：`shared_p2r0`，Gowin V1.9.11.03 Education，布局算法 2、布线算法 0、最大扇出 23。

|---|---:|
| Logic | 22210 / 23040 |
| CLS | 11381 / 11520 |
| BSRAM | 46 / 56 |
| DSP | 26.5 / 28 |
| 主时钟目标 | 50 MHz（20 ns） |
| PnR Fmax | 50.717 MHz |
| 最差 Setup 裕量 | 0.283 ns |
| Setup / Hold 违例端点 | 0 / 0 |

32 声部通用/预设 FIFO 两配置各 800 帧、25632 份完整上下文对比通过，最坏 950 时钟，小于 1024。变调 180000 次逐时钟对比、LED 179908 次逐时钟/全引脚对比、共享传感器快照队列 249980 次逐时钟/PCM 对比通过。整机事件录制/重放/Flash 提交及回传通过，492 个采样与外部 I2S、HC-05 和 Java WAV 逐个一致；下载期间音频和 HUB75 连续运行。

`reports/` 包含资源、完整时序、引脚、实际构建脚本及仿真/APP 测试日志。`SHA256SUMS.txt` 可核对文件。源码包包含冻结 RTL/ROM/约束、APP 源码及复查脚本；88 项硬件输入与成功构建的 SHA256 一致。

源码构建入口为 `pcm5102_pam8403/tools/build_unified.tcl`，项目为 `PCM5102_UNIFIED.gprj`。源码包不包含 Gowin、Android SDK 或签名私钥，SDK 可由原有 `prepare-sdk.ps1` 准备。

本包已完成电脑端仿真、目标器件布局布线及静态时序验证；尚未替用户烧录开发板或安装手机进行真机测试。
