# 演奏参数运行时调节

2026-10-21。器件 GW5A-LV25MG121NC1/I0，工程 `PCM5102_UNIFIED.gprj`，顶层 `top_unified` → `top`。本阶段音频由 DDS / TDM / Karplus–Strong 现场合成，无预录音频参与本页参数测试。台架仿真、构建与实物对录分别记录。

## 当前范围

C1 弯音范围、C2 分数步进滑音、C3 颤音速率、C4 颤音深度、C5(a) 全局起振等待、C7 全局移调 / 标准音已通过分项仿真及完整构建。四档回声与合唱速率完成原型仿真和资源评估后超预算，已撤回活动固件与App。C8律制和C6震音原型也因超预算撤回；当前范围停在C7。电位器 ANALOG=3 仍为旧版单向下摆，不能把它描述为已对称化。

用户已确认两项范围变更：E 的预留由 280 降为 100 CLS，保留 B2、D 和安全垫；长回声允许湿声降采样，保留四档。E 的范围复核见 [E_SCOPE.md](E_SCOPE.md)。

## 协议与容量

唯一链路为 HC-05 SPP，9600 8N1，ASCII，一行一条，App 补 LF。命令区分大小写、没有空格，最多64字符，不含 CR/LF；超长回 `ERR,LENGTH`。设置字段为无符号十进制原始寄存器值，查询回复为定长大写十六进制，末尾 CRLF。

| ID | 设置字段 | 查询 | 回复 kind / 长度（含 CRLF） |
| --- | --- | --- | --- |
| 59 | `PITCH,lower,upper,slewQ8_8,baseQ2_14` | `PITCH,?` | 27 / 27 |
| 60 | `VIB,incHi16,incLo16,depth,delayFrames` | `VIB,?` | 28 / 24 |

现有1～58号保持，AREC七项仍占原位，统一固件回 `ERR,STATE`。当前共60条字典，61～63未分配；译码生成器同时生成 `hc05_keymap.v` 标记区，不能手改生成物。回复原27条逐字保留，末尾追加2条，kind29～31仍为空。

设置成功 `OK`。空字段及省略的尾字段保持原值；整行解析并校验后原子提交，失败不修改任何寄存器。裸前缀如 `PITCH,` 不构成有效设置；多余字段、非数字、错误大小写回 `ERR,CMD`，寄存器或累加器越界回 `ERR,RANGE`。

```text

PITCH,,,175
PITCH,,,,19573
VIB,10,48327,948,9766
```

默认查询（显示的十六进制不可直接当作十进制设置值）：

```text
PITCH,2000,8000,1000,4000
VIB,0008,0D96,100,0000
```

### 弯音与滑音

`ratio=round(16384×2^(cents/1200))`。±100音分为半音，±200为两个半音，±1200为八度。App 使用对称范围；底层上下界可以分别保留，查询返回实际值。

滑音时间定义为**原音到当前正向范围上限**的全程时间：

`stepQ8_8=round((upper−16384)×256/(ms×Fs/1000))`。

每帧分数累加，允许某些帧不前进，解决小范围500 ms时整数步进会变零的问题。原默认4096精确等于每帧16：原音上行八度20.97152 ms，下行八度10.48576 ms。其他目标距离按比率距离缩短，并非每次变音都耗同一个毫秒数。小范围长时间的最差量化误差约11%，界面显示量化后的实际全程时间。

范围只作用前七个扫描键的 `BEND,1..7`；修改范围须松键、等待释音完成、停止曲谱及下载。滑音和移调可在发声或曲谱播放时更新，更新不重置声部相位。App 弯音拖动按已回读的上下界限幅，旧草稿超范围时说明具体原因并拒发。

### 颤音与起振

`inc=round(Hz×2^32/Fs)`；`depth≈round(cents×256/27)`；`delayFrames=round(ms×Fs/1000)`。深度换算保留旧固件的线性频率近似，±100音分不是严格指数对称的音分摆幅；界面用“约”标明。中间 `lfo_scaled` 扩为有符号18位，避免深度大于256时符号翻转。

作用于生产链路的**红外 + 手势共享 TDM**。`VIBRATO,0/1`控制开关，`VIB`设置参数。起振采用C5(a)：从整体使能或成功应用VIB时重新等待，结束后逐帧渐入；不是每个音符独立等待。速率 / 深度 / 等待修改可在演奏中应用。独立 `vibrato.v` 的运行时接口另有回归，生产吉他 `geita.v`没有该颤音模块，不能将其算作受控音源。

自然颤音常见4.5～6.5 Hz、数十音分；较深与较快档用于明显调制。震音改变振幅，颤音改变音高，界面分开说明。

### 移调、标准音与叠加

`baseQ2_14=round(16384×2^(semitones/12)×A4/440)`。+3半音 / A4=442为19573；−12 / 415为7727；+12 / 466为34704。原Q0.16音高通路不能表示升调，因此基准倍率使用独立Q2.14寄存器并复用现有乘法时隙。

- 前七触摸键：映射音高 → FSR / 模拟用途倍率 → 基准移调 / A4 → 逐声部弯音。
- K8～K16：固定默认音高 → 原模拟用途倍率 → 基准移调 / A4。
- 红外 / 手势：事件固定音高 → 基准移调 / A4 → 共享颤音。
- Karplus–Strong吉他：保持固定音高；原曲谱引导与LED音符编号不随基准变调重排。

上行基准先归一化再做弯音，最终补回移位，保留26×16 DSP几何；极端组合相对理论整数DDS约有数个刻度的截位误差，不通过钳位掩盖升调。TDM用已有空时隙完成基准变换，32声部最忙帧仍小于1024时钟。

`ANALOG=2`电位器音高与非原音基准互斥，两方向都回 `ERR,STATE`；先恢复0半音/A4=440才可进入ANALOG2。FSR用途、音量、旧电位器颤音和湿度用途可叠加。所有新参数在事件录制、回放及日志占用期间回 `ERR,BUSY`。

### 未交付的回声 / 合唱原型

原型保持生产RAM **4096×16**，没有扩大地址宽度或深度；协议候选为62号 `EFFECT2,tap,chorusInc`，同前缀查询kind29 /16字节。该协议、模板与App入口已从活动版本撤回，当前发EFFECT2会收到ERR,CMD。tap0每帧存一个样本，tap1/2/3每2/4/6帧存一次；首版积分平均，后版试验一阶低通，读出的湿声在采样间保持。四档的名义回声周期为 `4096×{1,2,4,6}/Fs`。

切档会清尾音并从一组新样本开始；脉冲首次湿声实测仿真帧号为4096、8193、16387、24581，长档额外相位为一组结束所需的1/3/5帧，最大0.1024 ms。每个原始音频帧仍输出干声，84 ms档和合唱默认路径与旧版逐拍一致。

长档湿声采样率为24.414 / 12.207 / 8.138 kHz，奈奎斯特上限约12.2 / 6.1 / 4.07 kHz。积分平均和后版一阶低通都不是理想抗混叠滤波；会有高频衰减、残余混叠和保持波形。首版六点平均使用二进制移位加法近似1/6，整数平均误差不超过8个PCM刻度；低成本试验版使用 `filtered += (dry-filtered) >> {1,2}`，不新增乘法或除法。该取舍是用户明确接受的长抽头湿声降采样方案。

`chorusInc=round(Hz×2^24/Fs)`，默认256对应原16位相位每帧+1，默认三角波查地址完全相同。

BPM选档目标为 `60000/BPM×{1/4,3/8,1/2}` ms，App原型选择四档中绝对误差最小者，并显示目标、实际毫秒、拍数和误差；该入口已随超预算候选撤回。四档不是连续延迟，任意速度不能保证严格同步。
