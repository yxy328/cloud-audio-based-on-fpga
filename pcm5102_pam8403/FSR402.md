# FSR402 一路转换模块 + FPGA 片内 ADC

> 2026-10-18 / App v1.4：新增 8/16 键串行切换、完整 16 键演奏、滑杆与标定、音效/延音及八种红外/手势音色。新增接线和兼容范围以 [迁移说明](REFERENCE_MIGRATION.md) 为准；下文七键部分仍适用于前七键及原 8 键模式。

当前主工程使用 **GW5A-25 片内 ADC**，没有外接 ADC 芯片，也没有 SPI ADC 接线。
一路信号转换模块把 FSR402 电阻变化转换成 AO 电压；片内 ADC 再把电压采成数字力度。
参考的是用户提供的 `3.薄膜压力传感器模块使用方法之一.doc`，其中一路模块同时有 AO 和 DO。
DO 是比较器阈值开关量，只能表示是否越过阈值；连续力度使用 AO。

## 信号和音量方向

```text
FSR402 → 一路信号转换模块 AO → 22k/4.7k 分压 → GW5A 片内 ADC
                                                    ↓
                                             校准 / 音量或音高平滑 ← K8 切换
                                                    ↓
TTP229 K1～K7 → 独立 DDS/ADSR → 触摸混音 → 表达增益 → 与歌曲混音 → I²S
```

这份说明书的 AO 随压力增大而升高，所以当前 `FSR_ADC_INVERT=0`。
K8（OUT8）现在只切换压力表达模式，不再发出 C5。K1～K7 保持 C4～B4 七个独立音符。
每次确认按下 K8 切换一次，长按不会连续切换；上电默认音量模式。
启动校准期间已按住 K8 时，松开后再按才会切换。
K1～K7 使用 2ms 输入确认、约 10ms ADSR 释放；K8 保持 20ms 确认，歌曲保持约 100ms 释放。

| 模式 | 轻压到重压的变化 | 保持的项目 |
| --- | --- | --- |
| 音量 | 原触摸音量约 100%→25%，`FSR_GAIN_REVERSE=1` | 基础音高 |
| 音高 | 基础频率的 1 倍→0.5 倍，即原音→低一个八度 | 原触摸音量增益和 ADSR |

音高模式按压力线性改变频率，七个音符使用同一比例，DDS 不重置相位。
切换模式时音量和音高分别平滑回到目标值，音量全程约 15.73ms，音高全程约 10.49ms。
一个传感器共同控制七个音符；压力和 K8 本身不触发音符，歌曲音量、音高均独立。
`FSR_GAIN_REVERSE=0` 可将音量模式改为重压声音大，不改变 AO 方向或音高模式的方向。

## 接线：AO 电压须匹配 ADC

[Gowin ADC 原厂用户指南](https://cdn.gowinsemi.com.cn/UG299E.pdf) 指明 ADC 外部输入为 0～1V。
Word 图中的“FSR402 → 转换模块”可以直接连接，模块内已有信号转换电路。
这里增加的电阻位于“模块 AO → FPGA ADC”之间，不是给传感器本体再做一次转换。
Word 的 RP-C18.3-ST 标定例子列出 AO=0.5V、1.6V、3.2V，因此它没有保证 AO 限制在 1V 内。
图中电位器标注为 DO 数字阈值调节，不能据此认定它是 AO 量程调节。
若实际模块另有 AO 量程设置，且能保证整个工作范围始终为 0～1V，则可以省去外部分压，重新标定 ZERO/FULL。
本工程默认按该说明书模块配外部分压。
这里使用真实 ADC 输入模式，普通数字 GPIO 的高低电平读取不能替代采样。
不能把模块 3.2V、3.3V 或 5V 的 AO 原电压直接接到 ADC。

```text
模块 AO ── 22kΩ ──┬── J3 第36脚 / FPGA J8 / IOT56[A]（ADC 正端）
                  │
                 4.7kΩ
                  │
                 GND

J3 第35脚 / FPGA K8 / IOT56[B]（ADC 负端）── GND
```

分压比例 `4.7/(22+4.7)≈0.176`：AO=3.2V 时 ADC 输入约 0.563V；
AO=5V 时约 0.880V。该配置以 AO 不超过 5V 为前提，接线后先用电压表确认正端不超过 1V。
可在分压中点对 GND 接 100nF 作为低通滤波；两只分压电阻必需，电容可选。

| 模块/线路 | 接到哪里 |
| --- | --- |
| FSR402 两端 | 一路转换模块的传感器接线端，不分正负 |
| 模块 AO | 上述 22kΩ 电阻的输入端 |
| 分压中点 | FPGA J8，Dock **J3 物理第36脚** |
| ADC 负端 | FPGA K8，Dock **J3 物理第35脚**，接 GND |
| 模块 GND | 与 FPGA、分压下端共地 |
| 模块 VCC | 按实际模块标注的额定电压供电 |
| 模块 DO | 不接连续力度通路 |

J8/K8 是 FPGA 封装球号，不是 J8/K8 排针名称。
针脚位置可核对 [Sipeed Dock 官方原理图](https://dl.sipeed.com/fileList/TANG/Primer_25K/02_Schematic/Tang_Primer_25K_Dock_60033_Schematic.pdf)。
CST 的 `USE_ADC_SRC bus0 IOT56;` 把这对引脚配置为模拟 ADC 输入，PnR 报告为 `ADC_IN`、无上拉/下拉。
原音频、触摸八键和 SCL 接线沿用；此前的四根 SPI ADC 接线取消。

## 采样和校准

`gowin_fsr_adc.v` 直接实例化器件 ADC 硬核，使用 50MHz 派生的 2.5MHz ADC 时钟，
电压模式、bus0 外部 PAD、1024 次采样/64 周期抽取，每 1ms 请求一次转换。
请求保持 1.28µs；同步完成信号，先确认 ready 低再等待高，避免重复读取上一笔结果。
2ms 内未完成则保留上次读数并置超时标志，之后重试。

硬核返回的 14bit 数值按原厂定义满足 `输入电压≈raw/2048 V`。
本工程把它换算为 10bit 相对码 `min(raw/2,1023)`，再映射到数字音量。
14bit 接口宽度不等于 14bit 有效测量精度。数字饱和也不能保护超压的模拟输入。

| 顶层参数 | 默认值 | 含义 |
| --- | ---: | --- |
| `FSR_ENABLE` | 1 | 启用压力音量/音高，设 0 旁路两项 |
| `FSR_SAMPLE_HZ` | 1000 | 请求更新率，建议保留默认 |
| `FSR_ADC_INVERT` | 0 | 本说明书模块 AO 随压力上升；实际相反时设 1 |
| `FSR_GAIN_REVERSE` | 1 | 轻压大声、重压小声；设 0 则重压大声 |
| `FSR_ADC_ZERO` | 32 | 相对力度的静止/轻触死区 |
| `FSR_ADC_FULL` | 600 | 相对力度的最大演奏阈值，须大于 ZERO |
| `FSR_MIN_GAIN` | 16384 | 重压时最低增益 25%；设 0 可使最大压力静音 |
| `FSR_SLEW_STEP` | 64 | 每音频帧最大增益变化，完整跨度约 15.73ms |
| `FSR_PITCH_MIN_RATIO` | 32768 | Q0.16 频率下限 0.5，即低一个八度 |
| `FSR_PITCH_SLEW_STEP` | 64 | 每帧最大音高比例变化，全程约 10.49ms |

说明书的 RP-C18.3-ST、6000g 和曲线系数是示例，**不用于本工程 FSR402 的力值换算**。
这里的 32/600 也只是演奏映射起始值，尚未实物标定；不输出牛顿、克或千克。

1. 不施压时记录 `fsr_adc_raw` 和 `fsr_adc_sample`，检查 AO/分压后的电压。
2. 轻压、重压分别观察 `fsr_pressure_code`，确认压力增大时数字码上升。
3. 静止码略上方设为 ZERO，将正常演奏最大力度的码设为 FULL。
4. 用实际接触面积和材料重新试按，检查最小、最大音量及松压变化。

可在 GAO 观察：`fsr_adc_raw`、`fsr_adc_sample`、`fsr_adc_valid`、`fsr_adc_timeout`、
`fsr_pressure_code`、`fsr_target_gain`、`fsr_gain`、`fsr_pitch_mode`、
`fsr_target_pitch_ratio`、`fsr_pitch_ratio`、`touch_phase_increments`。
`fsr_pitch_mode=0` 是音量，`1` 是音高；未选中的表达量会平滑回到满比例。
