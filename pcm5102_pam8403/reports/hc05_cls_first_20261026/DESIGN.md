# 第一轮 HC-05 CLS 优化：功能保持边界

本轮只评估 `src/hc05_keymap.v` 的内部数据通路。基线为 2026-10-26 已验证的三效果/固定 16 键工程，102 项生产输入已逐项核对。器件、工具、50 MHz、resource_sharing=1、retiming=1、place2/route0/maxfan23 保持一致。

## 候选与结果口径

- `parallel_dispatch`：把互斥的 63 个命令 ID 改为 case 分发，保留原分支及额外条件。完整构建发生放置失败，26 个 LUT 等价单元未放入；11520 CLS 是部分布局统计，不是一个可交付版本。该候选不接入。
- `map_serial`：MAP 查询仍在 EXECUTE 时锁存全部七个音符，锁存二进制音符而不是七组已格式化十进制数字；发送时共用一组转换。已有移位寄存器每个动态字符仍移四位，新增两个位跟踪该音符的十位/个位和是否属于 70 段。MAP 写入改成七条固定 lane 的条件写回。全部键位、音高范围、UART 字节及节奏不变。
- `reply_parallel`：保留命令 FSM、所有校验、提交动作和回复格式，仅将 112 位回复数据寄存器的写入移到独立时序块，用小型 case 选择 17 个原有数据来源（AREC 的两种参数分支属于同一命令）。该版本没有将整个命令链改成 case，也没有串行化 MAP 格式化。

资源、布线和时序的最终结果分别保存在各候选的 `audit.json`；只有完整布通、setup/hold 通过且实际回收 CLS 的候选才可接入。最终采用哪个版本以 README 和 integration.json 为准。

`reply_parallel` 的原 place2/route0/fan23 完整构建少 50 CLS 和 180 Logic，但 9 个 setup 端点违例，原始最差 -1.586ns，位于传感器合成器到上下文 RAM 的路径。HTML 的限量路径摘要显示 +0.303ns，并不能替代违例端点和原始 timing_paths 检查，该位流不接入。

后续 `reply_place1`、`reply_fan12`、`reply_route1` 保持全部 RTL、ROM、约束和综合选项不变，分别只改布局选项、最大扇出、布线选项。重新构建并记录完整物理结果，功能测试按完全一致的 RTL 哈希沿用；若采用这些策略，最终收益包含 RTL 和物理策略的联合变化，不能全部算成 RTL 单独收益。

## reply_parallel 的可观察行为

1. 所有动态查询都在原 EXECUTE 边沿锁存完整数据，包含 VIZ 的 112 位原子快照、三效果配置/实际状态、TAKE 状态及七键映射。不存在把 live 输入延迟到 UART 发送时才读取的变化。
2. MAP 设置成功时，ACK 的键位和音高数字仍取自同一 EXECUTE 边沿的 line；映射写回和合法性检查保留在原命令 FSM。
3. 回复数据可以在被拒绝的查询或设置命令上提前写入，但拒绝/成功设置走原有静态回复模板。这些模板没有动态占位符，不会消费该数据；下一条动态查询一定重新锁存完整载荷。因此不要求内部 reply 寄存器在拒绝后与旧版相等。
4. RESPOND 阶段的移位条件完全保留：reply_char_ready、TX ready、日志/音频流/实时键事件的仲裁以及动态占位符必须同时满足。字符串、字节间隔和背压行为不变。
5. UART 故障和实体按键优先级仍由原 FSM 处理。故障取消 EXECUTE 时可能发生的内部载荷写入没有有效回复与之对应。

## 验证方法

`prepare_differential.py` 从冻结原 RTL 生成独立参考模块，为原有串口测试注入同输入参考实例，在每个时钟检查全部 67 个输出，包括 TX 和所有控制值/脉冲；内部刻意注入的故障同时注入参考。比较范围是测试激励下的外部行为，不声称完成任意状态的形式等价证明。

覆盖 MAP 全部键位/13 个音高、DDS 步进、无效/超长/二进制/坏停止位输入、忙状态、硬件按键竞争、扩展控制、三效果、TAKE、ADSR、弯音、视觉与 XY、曲谱下载及旧音频录制参数分支。原有单实例断言继续运行，没有修改预期回复来适应新实现。部分原测试保留未连接的可选输入，不能据此声称所有可选传感器组合均已穷尽。

整机另跑固定 16 键极性恢复、真实 UART/TTP229/双 ADC 的并行帧期限和 TAKE 回放、旧新 TAKE 字段以及 528 位原子快照检查。音频算术、音色、效果器、存储布局、RAM 数量和外部引脚均未作为本轮裁减手段。

没有烧录 FPGA、写板上 Flash 或做实板听音。保留源文件/工具哈希、实际综合与 PNR 配置、原始 timing_paths、失败诊断及旧默认位流，供复核与回退。
