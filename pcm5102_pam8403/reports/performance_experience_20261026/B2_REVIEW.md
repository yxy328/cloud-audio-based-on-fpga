# B2 末尾依赖复核

本轮没有实现完整 B2，也没有完整 B2 构建，不能给出最终 CLS 成本或声称确定放不下。它继续保留为后续候选；本轮判断为**几何与录放兼容前置设计未满足**。若原 D 最终未接入，还同时缺原 D 依赖。

| 当前代码事实 | 完整 B2 所需的前置变化 |
|---|---|
| TTP229 固定16键，前12键为 C4～B4，后4键为 C5/D5/E5/F5 | 踏板必须增加可选择模式并默认保留现有高音键，不能直接取消已交付的四个音 |
| `note_map` 56位、`MAP?`七项、MAP请求固定8字符 | 12项映射、两位键号、旧七项请求兼容与分页/聚合回复；当前63个命令ID已满，必须扩展已有族 |
| `midi_note_lut`七项步进共224位；`voice_pitch_scaler`七键目标，3位索引 | 12项步进/目标、索引和扫描调度；保留手动弯音和曲谱目标的作用范围与冲突规则 |
| `downloadable_song` 把13种 MIDI 音高映射为7个键；`guide_keys`、`spawn_keys`为7位 | 12键映射与指引/试听的整个通路一起扩宽，不能只改手机绘图或下载格式 |
| `touch_tdm_synth.low_steps`七项，后九项由固定常量及压力流水线产生 | 前12键可映射后重排音高来源；高键、压力、16音帧期限均需重新核对，不能照搬1012拍结论 |
| 当前528位 TAKE 保存前七项实际步进，后九项依固定音高恢复 | 新的12键映射/动态弯音/踏板需定义可复现快照；直接增加5×32位会扩大每事件记录，须先检查RAM/NOR几何和新旧格式兼容 |
| 手机琴键已有12键几何，设备指引与曲谱仍7通道 | 既有12键外观不能当作固件12键可映射已完成；物理指引、试听与导入检查均需覆盖 |

直接扩宽记录的一个候选会把步进字段由224增至384位，即额外160位；若保持1024条记录，原始位容量增加163840位，尚未计入深度/端口取整及控制成本。这只是该直接方案的数据几何，不是所有压缩/重算方案的下界，也不是已经测出的整机 BSRAM 增量。

后续应先选择保留全部现有能力的映射/指引/录放格式，再做单独原型与完整构建。不能借 B2 减少128条曲谱、60000ms时长、1024条TAKE或取消原有音源来制造通过；也不能把历史200 CLS当作当前预留。新方案从本轮最终实际余额重新准入。
