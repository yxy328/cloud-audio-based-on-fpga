# 三效果本轮接口与验收边界

用户将混响和三效果置于后续扩展之前。本轮暂不占用尚未实现的 D/B2/E 的 1650 Logic / 330 CLS / 4 BSRAM 预留，仍保留 35 CLS 安全垫；已有功能保留，不把扩展称为已完成。

固定顺序为现有总混音 → CHORUS → DELAY → REVERB → 总音量 → I2S。使用 2048/4096/4096 个独立 16 位采样历史，一套乘法器在插值、湿声量、反馈间分时。效果器约 50 拍的独立期限不与触摸/弯音的并行硬件占用相加。

- 合唱：65536 帧 LFO 周期，Fs=48828.125Hz；15位三角相位形成 Q8 分数延迟，四档调制幅度约32/64/128/256采样，基准1024采样，两个相邻历史样本作线性插值。
- 延迟：4096采样，四档湿声捕获间隔1/2/4/6帧；长档先低通湿声，干声保持原采样率。反馈四档1/4、1/2、5/8、3/4，输入写入增益1/2。旧延迟命令恢复原1/2反馈。
- 混响：Fs/2，四条并联comb为618/658/707/751，后串308/244 allpass；并联输出取四路平均，comb输入为相邻两帧之和除16（平均后1/8，留出最大反馈余量）。comb反馈10/16、12/16、13/16、14/16，allpass反馈1/2。
- 所有反馈及湿声量按有符号向零截断，避免负数移位产生持续负1LSB尾音；各阶段16位饱和。三块湿声量独立0..8，实际增益0..1/2；保留原dry+wet语义。
- 开关、合唱深度、延迟档或混响预设改变，只重置对应块的历史有效性；湿声量及延迟反馈改变保留已有尾音。PANIC、回放清尾和全局reset清整链。

## 协议

不增加命令ID；回复kind0..29保持，kind30用于EFFECT3，31仍保留。

| 命令 | 行为 |
|---|---|
| EFFECT,0,w | 三块旁路；三块配置湿声量均写为w |
| EFFECT,1,w | 仅延迟，反馈恢复1/2；保留四档延迟选择 |
| EFFECT,2,w | 仅合唱，调制深度选256采样；现为分数插值，保留原用途及LFO周期，不声称与旧阶梯波形逐样本相同 |
| EFFECT,3,m,s,w | 扩展四数字原子写入，m为0..7掩码，s为8位配置，w为12位三个湿声量 |
| EFFECT,? | EFFECT3,m,ss,www,a,tt,vvv：配置掩码/配置/湿声量与实际应用掩码/配置/湿声量，均为定长大写十六进制 |
| EFFECT2,t / EFFECT2,? | 保留旧四档延迟写入/回读，与配置位3:2共用同一寄存器 |

s位1:0=合唱幅度，3:2=延迟档，5:4=延迟反馈，7:6=混响预设。w的低/中/高nibble分别是C/D/R湿声量，均须0..8，其他位拒绝。默认mask=0、s=0x52、w=0x444。CTRL/CTRL2按延迟优先、否则合唱、否则0投影旧效果枚举；新App读EFFECT3，混响单独开启不会被误认成全旁路。

滑杆ANALOG4继续作为湿声控制，覆盖三块实际湿声量；配置值保留。回复同时包含配置与实际应用状态，回放时实际字段来自录制状态。新App显示这两种状态的区别。

## 528位TAKE

位511为新格式标志；设置放494:487，掩码放486:484，三块有效湿声量放431:420。音符、音源控制、ADSR、压力/音高、总音量等既有字段不移位。记录仍为同拍528位原子快照。

位511=0的旧录制按旧mode0/1/2映射旁路/延迟/合唱，湿声量取旧字段。旧录制没有保存延迟档，继续按回放时当前档位处理，不声称恢复了不存在的字段。新录制保存全部新效果配置及滑杆实际湿声量。

本文件定义接口；只有样本模型、脉冲响应/衰减、协议/TAKE、整机资源/PnR/时序、App及期限验证完成后才交付。实物音质和模拟音频对录由单独验收确认。
