# 十二键音游：玩法、外观与计分

对应用户确认的“两种都要”：玩法种类与外观同时扩展。沿用 K1～K12 自定义 MIDI 映射，K13～K16 继续发声与显示底部键态。曲谱仍是 128 条、每条 1～60000 ms 的原格式，不新增不可兼容的曲谱字段。

## 使用行为

- 单点：短于 500 ms 的非休止事件，或关闭长按玩法后的所有非休止事件。需要一次新按下，提前按住不能重复计分。
- 和弦：同一事件的所有目标列均须出现新按下，整体记一次判定和连击。多键可以在窗口内分别到位；最差键的时机决定 Perfect/Good。
- 长按：开启长按玩法时，时长至少 500 ms 的事件用紫色音符头提示。所有目标键到位后，持续按至该事件结束才计分；提前松开或 STOP 打断记 Miss。判定线下的紫色标记表示当前需要保持。
- 重复音/连打：保留曲谱中的相邻重复事件，每条都须松开后重新按下。不会把同一持续高电平当作多次击打。
- 休止：不计分，也不增加连击。自动演奏 AUDITION 不计分；真实触摸输入用于 PLAY 判定，虚拟音频门控不充当按键。
- 同一 MIDI 音高若映射给多个扫描键，这些列仍会同时提示，并按和弦处理。需要单键对应时，应使用不同音高。

Perfect 1000 分、Good 500 分；长按完成额外 500 分。Miss 清除当前连击。最高连击及 Miss 次数可在手机回读；LED 顶部青色六位为得分，黄色三位为当前连击。曲谱结束或 STOP 后保留本次结果，重新开始时清零。128 条全部 Perfect 长按的上限是 192000 分、128 连击。

## 判定与显示设置

四档窗口分别为 ±80/120/160/200 ms，Perfect 为对应窗口的一半；窗口边界包含在内。后一个事件开始或当前事件结束时，前一个尚未完成的判定关闭。短事件的延后窗口因此会被事件边界截短。每个按下边沿只能被消费一次；过期缓存不能在时钟回绕后重新命中。此版不处罚空拍多按的额外键。

薄音符固定一像素高，宽度可选一/二像素；配色有霓虹青蓝、暖金、简洁白，长按保持紫色。击打反馈为约 180 ms 的短光柱/渐暗闪光：Perfect 白色、Good 金色、Miss 红色。可关闭特效，或把长音全部按点按处理。

手机主页曲谱控制后新增“十二键音游”卡片，支持应用设置并回读确认、手动读分、开始/停止自动刷新。播放期间拒绝改设置。断连、预览停止和回读超时不继续标成实时数据。设置作用于板上判定；蓝牙回传延迟不参与计分。

本版没有下落长音尾条、滑键/划键、独立谱面类型编辑、速度调节或延迟校准；长按类型由当前事件时长和设置共同决定。

## 结构与协议

曲谱阅读器新增明确的事件开始/结束脉冲和当前时长。相邻同键事件因此不会被合并成一次判定。第一条在预备结束时发出一次开始脉冲；休止也有边界脉冲，供上一条正确结算。前瞻头部携带独立长按标记，与音高掩码一起经过原位置流水。

判定器与曲谱共用同一个毫秒使能。十二个按下时间戳在同步 RAM 中循环扫描，每列三个时钟；九位模时间和有效标记避免过期边沿回绕。四档有符号时差判定、500 分积分到 BCD、三个统计数到 BCD均由同步 ROM 完成。计分统计采用相同的寄存读取延迟。

游戏位图为 64×24 位，每列各有点按/长按位，不以 128 组计时寄存器保存屏幕内容。上下半屏各读一个音符行，替代旧三像素厚度的六份读副本。开始时用 64 个空闲写周期清图，此时 note_ready=0；每次滚动以空闲写槽清除新顶行，插入优先。顶端十行不属于下落可见区域，因此短暂延后清行不会形成可见旧音符。note_ready 在待清行时反压，持续突发也不丢已接收音符。七列通用模块保留旧有效位与三行字形路径。

传感器四份 ADSR/音色暂存改用同步宽 RAM，通过预测下一读标签及显式同址转发保留原来的出队时刻和原子快照。队列、溢出、所有发出的配置事件以及 PCM 已做逐周期对照。按键上报 FIFO 改为独立无数据复位的 RAM 进程；对外字节序列和背压逐周期对照。原声部数、音色、音频帧期限及 TAKE 格式保持。

构建保留 native 32/36 位存储器，`Convert_SDP32_36_to_SDP16_18=false`，以免把 24 位屏幕行拆成两块。此为必要构建配置；新建快照时，构建工具会连同 RTL 一起冻结工程的 process_config，避免复现时悄悄回到旧转换选项。最终资源、时序和发布状态以 README/构建审计为准。

复用原 `VIS` 命令 ID，不扩充已占满的命令编号：

```text
VIS,0,<settings>     # 十进制 0..255；播放中 ERR,BUSY；成功 OK
VIZ?                 # 曲谱页返回 V,<28个大写十六进制字符>
```

settings 从高到低：计分使能、长按、特效、两像素宽、难度两位、主题两位。默认 228 / 0xE4；App 提供三个主题，协议保留的主题 3 使用默认青蓝。旧 `VIS,0..3` 和 `VIS?` 继续可用。

曲谱/结果页 VIZ 的版本为 2：

| 位 | 含义 |
|---|---|
| 111:108 | 版本 2 |
| 107:100 | settings |
| 99:96 | 会话存在、playing、holding、判定进行中 |
| 95:92 | 最近判定：0 无、1 Perfect、2 Good、3 Miss |
| 91:68 | 六位 BCD 得分 |
| 67:56 / 55:44 / 43:32 | 三位 BCD 当前连击 / 最高连击 / Miss |
| 31 | 已在 PWM 帧边界锁存的状态总览页标记 |
| 30:0 | 保留为零 |

波形/XY/频谱页仍使用原版本 1 VIZ。VIS? 对版本 2 也保留真实的总览页标记。App Code41 能区分两版。新版码流应配套 Code41；旧 App 的版本一预览器不能解析曲谱页的新计分包。

## 验证重点

新增测试覆盖单点/和弦/重复/长按、全部四档窗口的正负边界与超界、过期时间戳回绕、128 条满分/满连击、STOP 中断长按、重新开始和禁用。外部 RGB5/PWM 引脚验证薄头、长按色、保持线、特效与数码字形，并导出面板图。

独立 64 行模型核对 6500 ms 滚动回绕、两类掩码、994 个密集头部、清行反压及 STOP 后重新清图。整机通过 UART 下载谱面/设置/读分、真实 TTP229 串行模型按 K1/K12、点按+休止+长按得到 2500 分，核对明确事件边界、AUDITION 排除以及外部 I2S。旧显示模式及按键上行另做回归；实际手机蓝牙与板上显示/触摸延迟仍需实机验收。
