# 执行方式说明

最初计划复制原综合网表，以 run pnr 只重跑物理实现；freeze.json 的 synthesis_inputs 是启动前复制并校验的文件，不是最终消费网表一致性的证明。

Gowin 新目录缺少已完成流程状态，run pnr 实际自动触发了综合。没有把自动重综合隐去，也没有把源文件哈希相同表述为网表字节相同。三组源输入仍与各自的 place0 冻结版本完全一致，综合选项与器件未改，唯一改变的物理实现设置为 place_option=1。最终实际综合 .prj、PnR cmd.do、device.cfg 和加密 .vg 的新旧哈希，由 collect.py 在 build_audit.json 中记录。

Gowin 的 .vg 使用 pragma protect 加密；无法靠去掉生成时间和路径注释比较内部电路。所有层级资源 XML 可直接比对，本轮三组在重新综合后均与自己的原版本完全一致；这只是映射计数一致的证据，不是形式等价证明。本轮未更改 RTL，既有 RTL 功能测试适用。

本轮应称为同一冻结源码、相同综合参数的 place1 重建，而非仅消费旧网表的 PnR。旧 place0 报告保持不变，不覆盖之前的失败证据。
