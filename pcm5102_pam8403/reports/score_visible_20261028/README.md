## 修复与资源

字库改成显式一位向量 `reg [0:0]`，按一位二进制数据加载，读取时显式选bit0。另将音符层、HUD层的像素结果单独保留，避免综合时的额外逻辑展开；扫描仍为每行133时钟。

整机还将上电复位终值解码寄存，移除高扇出复位信号前的组合解码；实际top模块测试确认仍在第63个时钟释放复位并保持释放，256个时钟全部一致。曲谱计时模块未改变。

Logic 22902、CLS 11504、Register 11516、BSRAM 55、DSP 25；剩16 CLS。50MHz完整布通，setup/hold违例均0，最差余量 +0.598/+0.178 ns。 BSRAM余1块。最终候选 `score_visible47_r`，place2/route0/maxfan23，原生32/36位BSRAM。
