## 1. 完整接线

下面“球号”为 FPGA 封装引脚，“J3/J4/J5”为 Tang Primer 25K Dock 排针编号。
排针按官方原理图核对：[Sipeed Dock 原理图](https://dl.sipeed.com/fileList/TANG/Primer_25K/02_Schematic/Tang_Primer_25K_Dock_60033_Schematic.pdf)。
原理图只用于确认接线；赛题要求依据用户提供的文字原文。

### 64×64 HUB75E：保持原接法

| 信号 | 球号 | Dock 排针 | 用途 |
| --- | --- | --- | --- |
| R1 / G1 / B1 | G10 / G11 / D10 | J4-12 / J4-11 / J4-10 | 上半屏 RGB |
| R2 / G2 / B2 | B10 / B11 / C10 | J4-8 / J4-7 / J4-6 | 下半屏 RGB |
| A / B | A10 / A11 | J5-12 / J5-11 | 行地址 |

| CK | L11 | J5-8 | 移位时钟 |
| ST / LAT | K11 | J5-7 | 锁存 |
| OE | K5 | J5-6 | 低有效输出使能 |

面板为64×64、1/32扫描HUB75E，支持七轨落音/键位反馈、最终混音波形、可调参考李萨如、实际混音延时XY、实时FFT频谱和三组音源幅度条。
给屏幕单独提供足够电流的 5V 电源，与 FPGA 共地；RGB/控制线按当前接口电平接线。

| IR6 / ir_beam[5] | J1 | J3-22 | A4 |
| IR7 / ir_beam[6] | H2 | J3-25 | B4 |
| IR8 / ir_beam[7] | H1 | J3-26 | C5 |

采用参考工程的数字接收方式：**通光=0，遮挡=1**，输出应为 FPGA 可接收的 3.3V 逻辑。
如果现有模块输出极性相反，应修改接收逻辑/接线适配；5V 推挽输出不能直接接入 FPGA。
八路输入均为弱上拉；闲置通道可不接。上电必须先通光稳定 1ms 才准备好，随后遮挡
稳定 1ms 触发一个音符；一直遮挡不重复，重新通光稳定 1ms 后才能再次触发。
八路同时遮挡会依次派发八个事件；与手势同拍也分别保存。IR 不依赖 APDS 初始化。
它们是具有音色时长和释音的触发音符，不是“遮挡多久就持续多久”的门控弦。
音色、颤音与手势共用；`BANK` 不改变红外固定的八个音符。
避开了参考工程与 LED 冲突的 J4 管脚，也避开 B2/C2 的默认专用 I²C 功能。

默认TTP229使用八键直接输出、有效高模式；多键和弦还需模块本身启用多键输出配置。FSR 默认轻触较响、重压较轻；OUT8 切换到
音高模式后，压力对当前全部触摸音符一起产生平滑变调。压力不作用于红外、手势或吉他。
APDS 未插入时触摸、压力、红外、蓝牙、吉他、LED 仍可使用；启动时驱动会重试。
APDS 运行中掉电后重新上电，当前驱动需要整机复位，未实现总线自动恢复。

## 5. 核心评分口径

1. 只统计完整独立发声单元：独立相位累加、频率控制、包络控制。
   单波表中的谐波不能重复算多个振荡器；加法分量、FM 算子、并行弦应按赛题各自口径统计。
2. 本工程的 32 个 TDM 上下文各自保存相位、频率、包络状态，共享乘法器仍然保持独立声部。
   查表次数、八种音色、颤音 LFO 都不额外凑入这 32 路。
3. 核心吞吐量 = **同时活跃可闻的独立振荡器数 × 实际音频输出采样率**。
   当前设计标称采样率 `50,000,000/1024=48,828.125Hz`，
   32 路目标吞吐量为 **1,562,500 振荡器采样/秒**。现场应使用实测 LRCK 频率重算。
   立体声复制和过采样均不翻倍加分。
4. 即使另有七路触摸和一条弦，也不直接宣称已验证 40 路评分成绩；需要同时可闻、
   独立频率/声部证据和现场谱峰。当前提供稳定复现 32 路的 TEST32。
5. 用户提供的规则没有各项分值、权重或并列时排序，不能据此编造总分或“满分”。

## 6. 现场验证步骤与通过标准

本节是根据赛题制定的操作清单，不是新增的官方评分条文。

| 步骤 | 操作和观测 | 通过标准 / 证据 |
| --- | --- | --- |
| 上电静音 | IR 全遮挡或悬空，触摸不按，不发演奏命令；APDS 可先不接 | 不自行演奏；S1/S2 只控制曲谱指引，不触发自动音频 |
| IR 连奏与和弦 | 各通道先通光，遮挡/保持/移开；再同时遮挡 4 路、8 路 | 每次合格遮挡一次发音，保持不重发，恢复通光可再次演奏；多路不互相丢失 |
| 至少两个控制维度 | 按住一个触摸音，改变 FSR 压力；OUT8 切换到音高模式重试 | 音高选择与压力表达可分别控制；音量或频率连续改变，松手释音 |
| 五音色和颤音 | 依次 TONE 0～4，再 VIBRATO 0/1，演奏 IR 或手势 | 新音符音色改变；颤音可闻，无明显爆音；已响音符不因换音色突变 |
| 32 路核心验证 | 停止其他演奏/曲谱操作，发 TEST32；约 0.2s 后采 PCM5102 线输出 | 约 2.7s 测试窗口内存在 32 个对应主峰；避免麦克风自动降噪/限幅和 PAM8403 开关噪声 |
| 对应频率核对 | Fs 实测后，目标 `f[n]=(37+7n)*Fs/4096`，n=0..31 | 32 个不同频率；标称约 441.074～3027.916Hz；谐波杂散不能冒充新增声部 |
| 采样率 / 吞吐量 | 示波器/逻辑分析仪量 LRCK 与 BCK，采集 FFT | LRCK 标称 48.828125kHz，BCK 3.125MHz、64 BCK/立体声帧；32×实测 Fs 作为吞吐量 |
| ≤10ms 与 ≤5ms | 双通道示波器同步记录接收器数字沿和 DAC 模拟输出；另测遮光动作到接收器沿 | 报告起点、幅度判定阈值和传感器/DAC延迟；重复至少100次记录最小/平均/最大值，最大值才用于门槛判断 |
| 延迟抖动 | 空载与 32 路负载下重复上述测量 | 报告峰峰变化和上界，不把单次平均或数字仿真当作“无抖动”证明 |
| 纯硬件核查 | 展示 top→IR/gesture→tdm_synth→混音→i2s_tx、触摸 DDS/ADSR 和 geita | 解释上下文/共享算术、实时相位和包络变化；无预录 PCM 播放器；手机只传控制事件 |
| LED 脱机指引 | 不连接手机，从 S1 启动内置指引；S2 重启；再通过 App 下载另一曲谱 | 64×64 扫描正常，七轨落音及触摸反馈，停止/重启清除旧指引 |
| 多音内单声部连续变调 | App v1.2按住C/E/G，只拖E对应滑杆，再全部回正并叠加FSR | 仅指定声部谱峰移动，其余保持；回正后恢复；无重新起音，I2S不中断；不将蓝牙耗时宣称为本地低延迟 |
| 手机功能 | 改键、下载谱、记录与导出触摸/压力日志 | 每条 ACK、失败/超时处理正常；检查事件顺序，明确不是音频录音 |

TEST32 是现场实时合成测试指令，接收后初始化独立振荡器频率/时长，再逐采样计算，
没有保存或播放一段测试 PCM。任意红外/手势事件在测试期间仍会占用/替换声部，
所以频谱验证时应让接收器保持稳定，暂停正常演奏，且不要反复连续发 TEST32。
