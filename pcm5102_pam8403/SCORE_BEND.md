# 曲谱弯音

使用 App **1.38-scorebend / Code39** 与配套码流。曲谱中的每条音符或和弦事件可以设置一个弯音目标，按设备当前滑音速率靠近；和弦各音共用同一目标。

在曲谱页导入三列 CSV，预览每条目标，点击“校验键位并下载 / 重新下载”，成功后点击“自动演奏 · 已下载曲谱”。“导出当前曲谱 CSV”会保留目标。配套固件能力或弯音范围不满足时，App 会提示并停止下载。

```csv
pitches,duration_ms,bend_target_cents
60,1000,200
60,1000,-200
60,1000,0
REST,500,
60+64,1000,100
60+64,1000,
```

第三列支持 -1200..1200 的整数音分，仍受设备当前弯音范围限制。**空白**沿用手动弯音目标，**0**显式回正；休止行应留空。音符/和弦范围仍为 MIDI 60..72，实际七键映射必须覆盖曲谱需要的音高。每条时长上限 60000ms，总容量 128 条。普通两列 CSV 和原有 MIDI 导入继续可用；MIDI 非中心弯音、同一和弦内各音不同弯音目标会明确拒绝。

目标在自动演奏的事件边界选用，并经过现有音高扫描和音频帧；首帧可能仍在先前音高，滑入时间由进阶演奏参数中的弯音速率决定。现有全局调音与压力/滑杆音高继续叠加。物理触摸与自动演奏占用同一映射键时共享音高。PLAY 保持无声指引，不自动套用曲谱目标。

STOP、休止、曲谱结束或移除目标后，相关键按当前滑音速率返回各自手动目标，手动目标值本身保留。PANIC 沿用即时止音。板上 TAKE 记录实际生效的音高，回放无需曲谱文件；格式、事件容量和旧记录兼容保持。

协议保留 `SONG_CHORD,index,mask,duration`，可追加 Q2.14 比率：`SONG_CHORD,index,mask,duration,ratio`。比率 0 沿用手动目标，16384 回正，8192..32768 是允许的绝对比率范围。能力查询 `SONG_BEGIN,?` 返回 `SONGBEND,1`。END 与每次 PLAY/AUDITION 会重查当前弯音范围，失败 END 保留板上旧谱。
