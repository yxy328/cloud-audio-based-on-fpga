# 现有工程融合：触摸、压力、手势、吉他、蓝牙和 LED

入口仍为本目录 `PCM5102_PAM8403.gprj`，顶层 `src/top.v`。
`../ALL_IN/pcm5102_pam8403/` 保留为原手势/吉他分支，本轮修改在本目录。

## 功能与控制

| 功能 | 操作 |
| --- | --- |
| 七键复音 | TTP229 OUT1～7，默认 C4 D4 E4 F4 G4 A4 B4，支持蓝牙改键 |
| 压力表达 | FSR402，OUT8 每次按下切换音量/音高；只影响触摸声部 |
| 曲谱与 64×64 屏幕 | 安卓导入 CSV/MIDI、HC-05 下载；S1 开始/停止，S2 重启 |
| APDS-9960 | 上→下 C4、左→右 D4、下→上 E4、右→左 F4；高音组为 G4 A4 B4 C5 |
| 手势音色 | App 选择正弦、钢琴、长笛、尤克里里或鼓，再应用 |
| 手势颤音/音符组 | App 分别开关颤音、切换低/高音组 |
| 单弦吉他 | App 拨弦或 `GUITAR` 命令，每条命令触发一次，重新触发会重新激励延迟线 |

手势为一条可重触发声部，不是四条独立手势复音；触摸七键仍各有独立 DDS/ADSR。
吉他默认 `GUITAR_STRING_LENGTH=110`，约 441.9Hz，为固定单弦。
手势音色/音符组切换用于下一次手势，不会改写正在发音的音高或音色；颤音可实时切换。
所有音源共享 50MHz 时钟、48828.125Hz 音频帧使能和一套 PCM5102 I²S 输出。
默认自动曲谱发声仍关闭，下载谱只提供屏幕指引；实时触摸、手势、拨弦命令生成声音。

## 新增接线

| APDS-9960 | FPGA 封装球号 | Dock J3 物理针脚 |
| --- | --- | --- |
| SCL | H4 | 23 |
| SDA | G4 | 24 |
| 电源/地 | 模块按 3.3V 接线，与 FPGA 共地 | 按底板标记 |

SCL/SDA 为开漏接口，使用模块/外接上拉到 3.3V；FPGA 同时配置弱上拉。
APDS 使用轮询，INT 不接。这里的 SCL/SDA 与 TTP229 的 SCL/SDO 是两组不同信号。
TTP229 原来的 SCL 接地接法继续保留，不与 F6 输出同时连接；原触摸、ADC、
PCM5102、HC-05 和 HUB75E 的引脚保持不变，详见 README 和 RHYTHM_GUIDE。

初始化期间保持手势区域无遮挡。未连接 APDS 时仍可使用触摸、压力、屏幕、蓝牙和吉他。
上电缺少 APDS 时会间隔重试初始化，不产生有效手势。运行中若传感器断电再上电，
原驱动不会自动重写初始化寄存器，需重新给整机上电或复位/重新下载 FPGA；本版本不支持
I²C 时钟延展或卡总线自动恢复。
本次未接入独立红外对管，待用户提供模块输出、接线与触发用途后再加。

## 新增蓝牙命令

沿用 9600 baud、8N1、大小写敏感、CR/LF 行结束；每次等待完整回复后发送下一条。

| 命令 | 含义 | 成功回复 |
| --- | --- | --- |
| `GUITAR` | 实时计算并拨弦一次 | `OK` |
| `TONE,0`～`TONE,4` | 正弦/钢琴/长笛/尤克里里/鼓 | `OK` |
| `VIBRATO,0` / `VIBRATO,1` | 手势颤音关闭/开启 | `OK` |
| `BANK,0` / `BANK,1` | 手势低音组/高音组 | `OK` |

参数只接受上述一位十进制数字；一位数字超出允许范围返回 `ERR,RANGE`，
其他格式返回 `ERR,CMD`。上电为正弦、低音组、颤音关闭，掉电不保存设置。
命令接受不依赖 APDS 就绪；`OK` 表示控制已接收，不能证明传感器或扬声器工作正常。
`STOP` 只停止曲谱指引，不截断触摸、手势或吉他尾音。

演奏事件日志保持原格式，仅记录触摸键和压力状态，不包含手势事件、音色选择或吉他拨弦，
因此不能用该日志重建整段融合演奏。
