# 手机 LED 轨迹控制（v1.9）

后续 [v1.10 手机 LED 联动版](../LED_REMOTE.md)已增加远程切页、实际状态读回和实时频谱/幅度预览，需要同时更新配套 FPGA 位流。下文保留仅使用原有 XY 命令的 v1.9 操作范围。

安装包：[FPGA-Score-led.apk](dist/FPGA-Score-led.apk)。包名为 `cn.fpga.score`，versionCode 10，使用现有调试签名，可覆盖同签名旧版。原 v1.6 与 v1.8 安装包保留。

新增“LED 李萨如与音频轨迹”卡片，位于“曲谱与播放”之后。复用固件已有的 `XY,r,p` 命令，不需要为本次 App 功能重新综合或烧录 FPGA。板上原固件需要支持 XY 命令；已有功能与固件边界见 [音频可视化](../AUDIO_VISUAL.md)。

## 使用

1. 系统配对 HC-05，在 App 连接开发板。
2. 长按板上 S2 约 1 秒，按“总览/曲谱 → 波形 → XY → 频谱”循环进入 XY 页。
3. 在 App 点击八字、多瓣、圆、椭圆、直线或实际混音，收到设备 `OK` 后，卡片显示“最近确认发送”。预设会同时更新下拉框中的待发送值。
4. 需要自选参数时，选择 REF 频率比与相位，然后点击“应用所选轨迹参数”。选择 AUD 实际混音时，相位选择禁用，发送相位代码为 0。
5. 选择“实际混音”并现场演奏，可观察随声音变化的轨迹；参考图形 REF 由 FPGA 数学 DDS 生成，不随音量或演奏音高自动变化。

手机设置参数不会自动切 LED 页面。XY 页短按 S2 也能轮换图形；其他页短按 S2 会重启有效曲谱，切页请用长按。

## 按钮与协议

| 按钮 | 命令 | 含义 |
| --- | --- | --- |
| 八字 | `XY,2,0` | REF 1:2、0° |
| 多瓣 | `XY,3,0` | REF 2:3、0° |
| 圆 | `XY,1,2` | REF 1:1、90° |
| 椭圆 | `XY,1,1` | REF 1:1、45° |
| 直线 | `XY,1,0` | REF 1:1、0° |
| 实际混音 | `XY,0,0` | AUD 单混音延时 XY |

自选频率比为 1:1、1:2、2:3，相位为 0°、45°、90°、135°。通信使用原命令队列，每条 CRLF 结束，逐条等待 `OK`；正在下载或处理其他命令时，按钮与参数选择会禁用。

卡片显示的是“最近一次收到确认的发送”，没有查询板上实时 XY 状态。用 S2 选图、开发板复位或断线后，不应把下拉框视为板上当前值；断线、主动断开和重连均清除确认提示，需要重新应用。旧固件若返回 `ERR,CMD`，沿用原通信层的报错和关闭连接行为，不显示成功。

本版保留当前工作区已有的曲库、音源与板上录制界面。板上录制按钮另需支持 TAKE 命令的配套固件，与本次 XY 控制所需固件范围不同；数字 USB 录音的历史操作说明仍以 v1.6 安装包为准。

## 构建与验证

```powershell
.\test-core.ps1
.\build-apk.ps1 -OutputApk 'dist\FPGA-Score-led.apk'
```

通过 Java/D8 编译、APK 对齐、签名验证和 Manifest 版本检查。蓝牙测试覆盖全部 16 组 XY 参数、CRLF、分片确认、与事件/录制结束消息交错、收到 OK 前保持等待，以及旧固件拒绝命令。完整测试结果与安装包 SHA256 见 [验证记录](../VERIFICATION.md)。

尚未在实体手机与 LED 面板上联调。本版没有新增远程切页、设备显示状态查询或手机实时频谱预览；后续方案见 [LED 与 App 联动整理](../LED_VISUAL_APP_PLAN.md)。
