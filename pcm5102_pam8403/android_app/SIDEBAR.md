## 三态视觉

所有新增颜色来自 `Theme.java`；控件由 `SegmentButton` 绘制。

| 状态 | 视觉与无障碍 |
| --- | --- |
| 未选中 | SURFACE_ALT底、1dp GHOST_LINE、MUTED文字、无抬升 |
| 已确认选中 | BUTTON渐变、白色粗体、3dp抬升、左侧3dp白色实心指示条、setSelected(true) |
| 草稿选中 | SURFACE底、2dp PINK虚线、PINK_INK粗体、右上10sp“•待发送”、setSelected(true) + setActivated(true) |
| 禁用 | DISABLED_BG / DISABLED_FG，仍保留逻辑选择与文字提示 |

LED四页、XY六预设、演奏页签各有1dp组框。导航和演奏页签选择表示当前页面，TalkBack说明为“当前分区 / 页签”；LED选择表示设备实际值。
应用按钮有待发送标记，确认后回普通样式，旁边显示“✓已确认”。输入框的数字比较会规范化空格与前导零。
每个参数组及应用控件保留12sp作用范围说明，红外与手势共享参数不显示成两套独立配置。

## 状态与连接

`ControlState` 不依赖 Android。每个键保留草稿、确认值、所属分区；忙碌只改变可用性。

- 草稿与确认值相等时无待发送红点；不等或未确认时显示待发送。断开时保留草稿、清确认值和侧栏红点；重新连接后重新确认。
- CTRL2?、SERIAL?、CAL?、MAP?只更新实际值，不覆盖尚未发送的编辑；设备值在摘要与控件标记中显示。
- BEND确认来自对应命令OK；TONE / VIBRATO / BANK / ADSR没有查询，来自本次连接的对应OK，不推测默认已生效。
- ADSR_RESET确认恢复的是固件原始包络，图中草稿仍保留；没有读回参数时不把草稿误标为已确认。
- VIS?以activeMode和已发布XY为准。进入“显示”分区后前台约每2秒用现有VIS?刷新；VIZ预览的实际页 / XY也刷新选择。其他命令、日志、板上录制状态轮询期间让出队列。
- 外部S2切页时，若没有待发送改动则跟随设备；若有草稿则保留草稿，并显示设备确认选择。请求与实际帧尚未一致时，不提前把请求标为实际页。

## 抽屉与系统边距

不增加AndroidX、Material或其他依赖。手写FrameLayout覆盖层、280dp START抽屉、遮罩关闭、translationX动画；返回键先关闭抽屉。
原背景 / 照片 / 遮罩层仍位于内容下方。48dp标题条和内容一起接收系统栏、刘海与输入法安全边距，抽屉单独留出系统栏和刘海边距。
所有分区共用一条可见状态提示，下载或命令结果不会被隐藏在设备分区。
`lockedButtons`继续控制设备任务，参数输入在忙碌时暂停编辑；分区导航与手机本地录制仍可使用。

## 记录流程

板上事件步骤由 `TakeStatus` 和 `TakeWorkflow` 决定：可执行步骤高亮、已完成步骤打勾、未到达步骤禁用。
停止后“回放”和“保存”均可执行，允许直接保存；只有读回saved状态才勾选保存完成。
HOLD=2或POLY不是16时，开始按钮禁用并说明原因；“切到可录配置”发送HOLD,0和POLY,16并回读，不自动开始录制。
板上已有内容的覆盖与删除继续使用固件确认流程。

事件日志另校验8键直连、关闭延音、FSR用途与POLY=16，并提供切换配置入口。
当前统一固件可能未启用日志通路，REC_START返回拒绝时如实显示；板上事件和手机录制仍可独立使用。
不再探测AREC?；旧PCM命令在SPP发送之前被本地拒绝，不发送二进制ACK，不再创建HC-05回传文件。
