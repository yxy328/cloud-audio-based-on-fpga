# 120首共享曲库：简洁界面（Code47）

2026-10-28，App **1.46-cleanui / Code47**：[安装包](dist/FPGA-Music-CleanUI-Code47.apk)，默认入口为 [FPGA-Music-Unified.apk](dist/FPGA-Music-Unified.apk)。**沿用Code46 FPGA位流，超过128条仍需该配套位流。**

## 播放与音游

音游、下落指引和自动演奏共用同一份板上已提交曲谱。选择等级及带01起始序号的曲目，手机自动载入；点击“匹配键位并下载”，收到提交成功确认后：“跟谱演奏”发送PLAY并计分；“自动演奏”试听不计分。切换选曲只更新手机当前曲谱，下载成功后才替换板上曲谱。

独立“小星星示例”、长曲快捷按钮及重复的载入/下载按钮已移除；完整120首曲目仍保留，长曲可在列表中直接选择。默认选中并载入白银《伦敦桥》。

“文件与曲目详情”默认折叠，提供CSV/MIDI导入、当前曲谱音符预览、CSV导出，以及所选曲目的版本说明、原谱网页和含来源CSV。导入文件或载入四类音符练习谱后，主下载按钮改为“校验键位并下载”，保留现有映射；此时可点“切回所选曲库曲目”重新载入当前下拉选项。

“下载与格式说明”收纳容量、匹配键位、弯音格式及兼容提示。十二键音游默认只显示得分操作；难度、长音、闪光及四类音符练习谱位于“音游设置与练习谱”，规则位于“玩法说明”。所有折叠入口均可展开，原有下载、自动演奏、计分及CSV元数据保留。

## 曲库与长度

合计120首，青铜/白银/黄金各40首。原九首和默认白银《伦敦桥》保留；新增来源111首中58首保留全部旋律、53首明确标注节选。19首现在按原谱展开反复，13首超过旧128条容量，最长252条、103.571秒。没有靠重复收录或放慢速度凑数量。

单曲最多 **256条音符/和弦/休止事件**，每条1～60000ms；实际曲长取决于节奏。范围仍为MIDI60～72、最多十二种映射音高，原九首保持七键兼容。全曲和反复能容纳时优先保留；否则选取完整记谱小节并在标题及说明中标注节选范围，不折叠八度、不切断边界连音。

普通曲库使用AUTO类型，默认≥500ms为HOLD、短音为TAP；四类音符练习谱及note_type CSV继续支持DRAG/FLICK。CSV/MIDI导入、CSV导出和弯音目标均支持256条。

整个曲库保存在手机，板上只保存当前一首；仅增加手机曲目数量不增加FPGA资源。本轮单曲128→256属于FPGA容量扩展，需要新位流，但利用原物理块的空余深度，曲谱仍 **2块BSRAM**，整机仍54/56，DSP仍25。下载前清空暂存区代替写入标记，保留乱序覆盖和原子提交；计分与时间轴同步扩展。实际资源和50MHz时序见[本轮报告](../reports/score256_20261028/README.md)。

来源、逐曲版本/时长/指纹见[说明](third_party/oneill/README.md)和[catalogue.json](third_party/oneill/catalogue.json)。新增曲保留英文原名，不包含录音或现代伴奏。未安装手机或做真实HC-05试玩。

# 历史记录：APP 分级曲库（v1.8，九首）

安装包：[FPGA-Score-library.apk](dist/FPGA-Score-library.apk)。包名仍为 `cn.fpga.score`，versionCode 9，使用现有调试签名。原 `FPGA-Score-debug.apk`（v1.6）及事件录制预览包保留。此曲库功能沿用现有 `MAP?` / `MAP` / `SONG_*` 蓝牙协议，无需为曲库重新烧录 FPGA。

## 使用

1. 连接 HC-05，在“02 曲谱与播放”中选择青铜、白银或黄金，再选择曲目。首次打开默认选中白银《伦敦桥要塌了》。九首曲目随 APK 内置，无需联网下载 MIDI 或查找文件。
2. 点击“匹配七键并下载所选曲目”。APP 读取真实七键配置，只把未用于本曲的音高或重复键位替换为缺少的音高；保留已有所需音高的第一个键位。若有改动，再次读取并校验键位，随后逐条下载，收到 `SONG_END` 的成功确认才显示已提交。
3. 提交成功后，点击“自动演奏 · 已下载曲谱”试听，或点击 PLAY 开始屏幕指引。下拉菜单选曲本身不会替换手机上已载入的曲谱，更不会改变板上曲谱；“载入所选曲目”只更新手机上的待下载曲谱。
4. 原“从文件夹导入 CSV / MIDI”继续使用安卓系统文件选择器。“校验键位并下载 / 重新下载”仍严格核对键位，不自动改动用户导入文件的配置。
5. “保存所选曲目到文件夹 · CSV”可把内置旋律保存到自选位置，再由原入口导入、下载；导出的 CSV 包含来源与改编说明。“查看所选曲目的原谱网页”在外部浏览器打开对应网页，可使用网站原有 PDF / MIDI 下载按钮。

自动匹配会改变开发板键位；实际值显示在“七键音高”区域。期间断开可能留下已确认的部分键位；重连后再次点击曲库下载即可重新读取并匹配。曲谱仍在 FPGA RAM，掉电后需重下。所有曲目保持 MIDI 60..72、最多七种不同音高、最多 128 条事件。文件导入、曲库导出均不申请整盘存储权限，内置曲库也无需 INTERNET 权限。
