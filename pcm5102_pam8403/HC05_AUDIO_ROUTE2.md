# HC-05 路线2：现场PCM录制、停止后慢速回传

独立工程 `PCM5102_AUDIO_TAKE.gprj` / `top_audio_take` 使用现有 HC-05，固定9600bps、8N1。最终数字混音先存已有Flash，停止校验后传手机，保存、播放和导出WAV。不自动烧录。当前为数字验证完成后供实板验收的实验版；实际Flash读回、连续写速、蓝牙/手机吞吐及手机播放未实测。固定源码快照的最终资源、时序、产物SHA256和测试日志见交付包 `RELEASE.json`、`verification/`。

## 容量、等待和备选方案

`audio_sample` 在与I²S锁存相同的 `frame_ce` 捕获：50000000/1024 = 48828.125Hz，16位有符号小端单声道，I²S左右复制同一混音。未降采样、未压缩，保留静音、尾音、压力/滑杆、手势/红外、ADSR、音色、效果及音量变化。

| 演奏时长 | PCM字节数 | 9600bps逐包确认的串行线计算时间，约 |
| --- | ---: | ---: |
| 1秒 | 97656 | 1分48秒 |
| 5秒 | 488280 | 9分钟 |
| 10秒 | 976562 | 18分钟 |
| 30秒上限 | 2929686，2.794MiB | 54分07秒以上 |

上限1464843采样，实际29.99998464秒。5723个DATA包，加START/END共3032752字节，下行UART本身52分39秒；逐包ASCII ACK及初始握手约88秒。另有SPI读取、蓝牙调度、手机写盘同步和线程延迟，所以54分钟不是实测保证。首次建议只录1秒。

默认BSRAM53/56，余3个18Kbit块即使全作PCM也仅约70.8ms。FIFO只能缓冲短暂停顿，无法解决持续带宽或长录音容量；本路线依靠Flash离线存储。

8kHz/16位单声道30秒约480000字节，封装/ACK后仍约9分钟，须抗混叠滤波/重采样，会损失高频和瞬态。1/4原采样率约12.207kHz需约13.5分钟。4bit ADPCM约1/4容量和传输时间，但有损，多声部/瞬态需误差和听感评估。无损压缩率不能预先保证，且当前CLS很紧。这些均未启用。

提高波特率也未启用。假设115200bps，30秒原PCM裸数据理论至少4分14秒，封装/ACK约4.5分钟以上，仍不支持实时。实际需核对HC-05固件/AT配置、FPGA分频误差和手机SPP吞吐，并进行长时间CRC/断连/距离测试，不能依据此计算宣称可用。

事件TAKE记录控制事件并由板上重放；七键/压力日志还遗漏其他演奏信息。手机重新合成是另一种声音。这里的WAV来自最终混音实际采样。音频版关闭旧事件日志（REC_START拒绝）、EVENT_TAKE和USB录音以容纳新逻辑；实时演奏、声部、精确ADSR、曲谱和HUB75E保留。回传期间串口独占，手机遥控/LED预览暂停，板上硬件演奏及显示继续。

## Flash布局和提交保护

[Sipeed官方核心板原理图](https://dl.sipeed.com/fileList/TANG/Primer_25K/02_Schematic/Tang_Primer_25K_52300_Schematic.pdf) U1200标W25Q64；实际型号、保护位及完整8MiB内容仍需实物读回。运行时只接受EF4017，不自动修改芯片保护寄存器。

| 区间，末地址不含 | 用途 |
| --- | --- |
| 000000..100000 | 保留1MiB配置区，RTL禁止写入 |
| 100000..47E000 | 音频槽0 |
| 47E000..7FC000 | 音频槽1 |
| 7FC000..800000 | 保留原事件录制区，音频版禁止写入 |

每槽0x37E000字节，前4KiB为头，后为PCM。30秒只擦每槽前717个4KiB扇区（0x2CD000）：槽0至3CD000、槽1至74B000；其余不动。位流工具解析FS文本中的二进制载荷，确认配置小于1MiB，不能把FS文本文件大小当Flash占用。

启动校验两个已提交头、全部PCM CRC及规定填充，选最新有效代次；最新损坏可退回旧有效录音。准备仅选非当前槽，先检查将擦范围全FF，或本格式且PCM/填充完整，才擦除。未知、损坏、未完成槽拒绝自动擦除；中断产生的部分槽可能需要人工服务恢复，App无强制擦除入口。即使没有可用录音也先检查归属。

每次擦写执行WREN、WEL检查、WIP轮询，操作超时2秒复位SPI引擎。底层另限操作码、分区、4KiB对齐、256字节页界及长度，没有整片/块擦除或手机任意地址写入入口。

1024×16 FIFO吸收页写延迟；STOP在页写期间会锁存。停止排空后整段读回CRC32，写头、读回头，再单独写并读回提交字节。空录音、溢出、读回/提交失败不替换旧录音；到30秒容量正常自动停止并提交。下载与录制不能并行。

连续Flash写速仍需实测：一页256字节对应2.62144ms演奏，5MHz SPI传一页约0.43ms，剩余时间用于内部编程/轮询。持续最坏编程延迟可能超过预算；约20.97ms FIFO不能保证任意慢Flash无丢样。须测完整30秒、WIP延迟分布及CRC；超限拒绝提交、旧录音保留。模型长延迟/溢出验证失败处理，不能代替真实速度测量。

## 操作

1. 手工核对板卡、JEDEC、完整8MiB备份和布局。可先JTAG/SRAM临时加载。固化时必须确认编程器只修改配置保留区；编程器整片擦除会绕过RTL保护而删除录音。不自动烧录。
2. 安装配套 `FPGA-HC05-Audio-Route2.apk`（1.12-route2，Android10以上），配对并连接现有HC-05。若安装提示签名不同，先导出重要私有文件，不要直接清除数据。
3. 读取录音状态。启动有已保存录音时，全段CRC可能需数秒。
4. 准备30秒槽。擦备用槽，保留当前有效录音。717扇区若45ms/扇区约32秒，加扫描数秒；若400ms/扇区约287秒；App最多等待6分钟。实际器件参数须核实。
5. 开始，演奏，停止并校验。App检查错误、有效标志及代次更新；30秒自动停止后仍可点停止/状态确认。首次只试1秒。
6. 回传WAV时保持前台、亮屏、电量。遥控和预览暂停，可继续板上演奏。可中止/断开；重连等待FPGA五秒ACK超时后从头重传，不支持断点续传。
7. 完整后播放、用系统选择器导出WAV。文件先存应用私有files目录，名称带`.INCOMPLETE.wav`，每个ACK前同步已验证前缀及长度，只有完整验证后才更名`.wav`。断线、超时、丢包、CRC/长度错误或取消保留不完整标记。杀进程也不能当完整结束；重启可恢复最近文件。卸载/清除数据会删除私有文件，请导出重要录音。

WAV为标准PCM RIFF，整数采样率48828Hz；`srAT`块保存精确50000000/1024比值，PCM字不改。标准播放器忽略私有块时速率差约2.56ppm。没有隐式重采样。

## 命令、数据格式

命令CR/LF结束：AREC_PREP、AREC_START,0、AREC_STOP、AREC_ABORT、AREC_SEND,会话号、AREC_ACK,序号、AREC?。OK仅确认请求。SEND获OK后手机先进入二进制接收，再发AREC_ACK,65535启动。

查询返回 `AREC,b,p,o,v,S,E,GGGG,NNNNNN`：忙、已准备、溢出、存在有效录音四个0/1，状态/错误各1位大写十六进制，代次4位，已保存采样数6位。旧USB固件三个标志不能证明Flash提交，App音频入口不接受旧格式。

状态：0空、1启动检查、2已保存、3准备、4采样、5准备好、6停止校验、8回传、F错误。错误：1型号/启动、2未准备、3无录音、4擦除、5写入、6读取、7数据CRC、8头校验、9提交、A下载读取、B确认超时、C中止、D未知/损坏分区、E空录音、F溢出。错误时仍可能有上一条有效录音。

复用FAR1：16字节头（FAR1魔数、u8类型、u8标志、u16载荷长度、u16序号、u16会话号、u32首采样索引），载荷及2字节CRC16/CCITT-FALSE，FFFF/1021，不反射，覆盖头及载荷。多字节均小端。DATA最多512字节PCM，每包等匹配序号ACK；5秒超时保留板上录音，错误后从头重传。手机10秒无可校验进度断开并标INCOMPLETE。二进制期间FPGA忽略其他命令/格式错误，ABORT在包末边界生效。

START类型1、标志1、12字节载荷：u32时钟、u16分频、u8位宽16、u8声道1、u32总采样数；序号/索引0。DATA类型2、标志0。END类型3、标志1、4字节整段PCM CRC32，索引为总采样数。CRC32使用IEEE反射EDB88320、初值及最终异或FFFFFFFF。手机核对会话、长度、序号、采样位置、每包CRC和整段CRC才标完整。USB备用原标志0/8字节START保持兼容。

Flash头：0..3 FAT1，4版本1，5保留0，6..7代次，8..11采样数，12..15 PCM CRC32，16..19时钟，20..21分频，22位宽16，23声道1，24..27前24字节CRC32，28..31 FF，32提交字节（FF未完成/00完成），其余元数据FF。

## 构建、优化和验证边界

沿用触摸256×16串行上下文、传感器两份278位上下文和TDM共享乘法器，不缩声部/ADSR精度。新包缓冲同步BSRAM读取/预取，避免512路异步LUT读选择；头CRC逐字节积累，消除24字节组合长路径。音频目标裁掉旧事件日志释放资源。默认19506 Logic/10713 CLS/53 BSRAM不能作为该独立工程数字。

RTL覆盖型号/归属/写保护、页期间STOP、数据/头/提交读回、真实采样间隔下长WIP溢出、空录音、容量、重启/损坏回退、ACK超时。整机检查混音/I²S/Flash/UART逐字一致、TDM期限、回传发声、HUB75扫描及二进制独占。整机UART500000仅用于缩短仿真；准备扫描由独立存储测试覆盖，整机使用已擦槽夹具。APDS注入已分类事件，FSR关闭。App测试为JVM解析/文件/模拟SPP Socket、APK编译签名和标准WAV读取。
