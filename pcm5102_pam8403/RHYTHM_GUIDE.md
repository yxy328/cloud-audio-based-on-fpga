# HUB75E 七轨音游指引

生产工程 `PCM5102_PAM8403.gprj` 的 `top` 已接入曲谱前瞻与 `hub75e_rhythm_display.v`，驱动现有 **64×64、1/32 扫描、RGB各5位PWM** 面板。

七轨从左到右对应触摸键1～7。青色音符从 y=2 下落，y=54 是判定线；当前应按键显示橙色，底部实际按键显示绿色，与当前目标一致时显示白色。按键由原防抖模块提供，音频仍只由现场触摸实时合成。

下载有效曲谱后发送 PLAY 或按 S1 开始，预备1500ms后首条目标到达判定线。S1再次按下停止，S2在XY页面之外短按松开后从头重启；XY页短按只选参考曲线/混音。停止/重启会清空旧音符，但保留触摸反馈；断开蓝牙不影响已提交曲谱的指引。

S2长按约1秒按“曲谱→波形→李萨如→实时频谱→曲谱”循环，三个音频画面均保留[三组音源幅度条](AUDIO_VISUAL.md)。长按不重启曲谱；隐藏期间曲谱时序与位图照常推进。模式在完整RGB5/PWM帧边界切换，不复位扫描器。

支持单音、和弦、休止及相邻重复事件。当前版本显示音符头和时段目标，没有长音尾条、命中判定或分数。相距小于一个屏幕像素（约29ms）的事件合并为同一行的键位集合，毫秒曲谱计时仍逐条进行。曲谱限128条，面板采用64×7位滚动位图，不以128份计时寄存器存储在途音符。

## 接线

沿用旧屏工程的面板主信号，音频与触摸使用当前PCM工程接线：

| HUB75E | FPGA球号 |
| --- | --- |
| R1 / G1 / B1 | G10 / G11 / D10 |
| R2 / G2 / B2 | B10 / B11 / C10 |
| A / B / C / D / E | A10 / A11 / E10 / E11 / C11 |
| CLK / LAT / OE | L11 / K11 / K5 |

面板按原额定电压独立供电，与开发板共地。当前 `.cst` 已加入全部屏幕信号。旧工程的 dbg0=K2、dbg1=L1、dbg2=K4 不要接入，它们分别与 I²S BCK、DIN 和触摸键1冲突。触摸OUT1用K4，旧K1已用于DAC LRCK。

## 时序与资源

扫描、曲谱、串口和音频共用50MHz主时钟，毫秒脉冲为使能，不是新时钟。HUB CLK在移位阶段为25MHz；RGB在其上升沿前稳定20ns。每行64个移位时钟，消隐后切换行地址，再拉高LAT，最后恢复显示。每行133个主时钟，32行×32个PWM相位约367Hz。

前瞻读取器在事件距到时不超过1500ms时提交音符，显示端将其插入正确高度；休止仅推进时序，不产生头部。单份滚动位图供上下半屏共享，避免复制计时队列。`GUIDE_LEAD_MS` 默认为1500，至少52，修改需重新综合。
位置计算经过三级流水，每周期可接收一个音符；流水期间的滚动会补偿到提交行，停止/重启会同时丢弃未提交提示。

`src/rhythm_guide.v` 保留为独立队列式实验渲染器，生产使用上述位图显示器。

## 验证与板上操作

```powershell
& ./pcm5102_pam8403/tools/run_sim.ps1 -Tests tb_downloadable_song,tb_hc05_download,tb_hub75e_rhythm_display,tb_top_live
```

仿真检查面板实际引脚的64列/32行、移位/消隐/LAT顺序、RGB占空比、预滚下落、和弦、密集事件合并、触摸反馈及停止清空。集成测试通过UART下载曲谱，核对HUB输出和独立实时合成的I²S采样；实际结果和位流标识见 [VERIFICATION.md](VERIFICATION.md)。

板上用安卓App下载小星星，确认SONG_END成功，再开始指引：检查首音预备、七轨方向、重复音间隔、底部按键反馈。断开手机后用S1/S2继续操作，再验证中断下载保留旧谱。当前没有远程烧录或实体面板显示验收，颜色和行序仍需在用户面板上核对。
