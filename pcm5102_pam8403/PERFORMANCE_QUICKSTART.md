# 常用演奏操作

**2026-10-27：曲谱事件弯音已接入，App Code39。** [CSV、协议、试听与录放说明](SCORE_BEND.md)。旧三参数曲谱命令保留；能力查询 `SONG_BEGIN,?` 返回 `SONGBEND,1`。

配套手机包：`android_app/dist/FPGA-Music-Performance-Code35.apk`。打开后进入“演奏”。

1. **连接**：点击“连接 / 检查设备”，先在系统蓝牙设置配对 HC-05，再刷新并连接。连接只读取设备，不自动应用手机场景。
2. **音量**：回到“演奏”，查看最近设备回读。总音量滑杆是草稿，点击“应用总音量”才发送；0 为静音。压力继续作用于触摸音源，音量用途的滑杆受手机总音量上限约束。
3. **三效果**：选场景后点“应用所选三效果场景”。只有收到确认并读回一致，才显示配置确认。首批“原声、轻空间、温暖合唱、节奏回声”是候选参数，需听音后调整。
4. **保存场景**：点击“读取并保存设备配置为新场景”并命名。保存的是合唱、延迟、混响的设备配置；支持重命名和删除，不包含总音量、音色、ADSR、压力或滑杆临时值。
5. **止音**：点击“紧急止音”释放声音与效果尾音，停止曲谱并关闭延音；按住的键要松开重按。手机命令仍受蓝牙传输及当前命令响应时间影响；固件收到 PANIC 后立即清音。

“配置”是设备参数，“实际”是最近读回的实际效果，“草稿”是尚未发送的控件选择。三效果逐项设置在“声音”；每张卡独立应用，读取设备或切场景不会覆盖三张卡的未提交草稿。需要同步控件时，手动点“采用设备…配置为草稿”。

滑杆选择“音效湿度”时，会用一个位置覆盖三块效果的实际湿声，配置值保留。TAKE 回放也会覆盖实际效果，回放期间应用场景并不代表正在回放的声音立刻变化。应用失败时查看已知实际状态；状态未知或超时断开后，重连读取再操作。

“展开 / 收起进阶演奏参数”可找到触摸、红外、手势参数。“声音”还提供逐项效果、共享移调、滑杆用途与端点标定；“设备”提供完整状态、ADC、串行极性与外观。没有实现的能力只有说明文字。

| 记录方式 | 保存内容 | 回放 / 导出 |
|---|---|---|
| 手机音符 / MIDI | 手机琴键事件，或开启板键联动后收到的键事件 | 手机本地命名、回放、改名、删除、导出 MIDI；不是原音录音 |
| 板上 TAKE | 按键、音源及已支持的演奏状态快照 | FPGA 回放；手动保存到板上 Flash，等待校验完成；不提供音频文件导出 |
| 旧事件日志 | 旧固件的文本事件 | 固定 16 键固件不提供此通路 |

TAKE 录制前关闭钢琴踏板并将复音上限设为 16；“记录”页会显示不可录原因和一键配置。停止后可直接回放或保存。连续表情变化会消耗 1024 条事件容量。K13～K16 仍是 C5/D5/E5/F5 高音键。
